Dokumen untuk pengembangan Laravel

Baca promt.md untuk instruksi coding bertahap dan PRD v4.6 untuk aturan fitur, data, dan pengujian. Ketiganya termasuk dalam ZIP: task.md untuk checklist pengerjaan.

Halaman ini hanya untuk memvisualisasikan PRD SaaS SMK v4.5. Operasi ditampilkan memakai data demonstrasi di browser; bukan backend Laravel, bukan transaksi sekolah sungguhan, dan tidak menyediakan autentikasi riil.
